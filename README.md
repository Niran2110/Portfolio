## 💻 Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/Niran2110/my-portfolio.git
   ```

2. Open the project folder:

   ```bash
   cd my-portfolio
   ```

3. Open `index.html` in your browser, or use the Live Server extension in Visual Studio Code.

No backend server or build process is required for this static portfolio.

## 🌍 Deployment

This portfolio can be hosted for free using GitHub Pages.

1. Push the project files to the `main` branch.
2. Open your repository on GitHub.
3. Navigate to **Settings → Pages**.
4. Select **Deploy from a branch**.
5. Choose `main` and `/(root)`.
6. Click **Save** and wait for deployment to finish.
